# مساعد الأريج — نموذج خدمة عملاء عربي

واجهة Streamlit عربية محسّنة مبنية على مشروع eyad-amir/arabic-chatbot-demo.

## التشغيل

```sh
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## الإمكانات

- واجهة عربية بألوان وهوية متجر عطور تجريبي.
- أمثلة أسئلة جاهزة، محادثة جديدة، وتنزيل المحادثة كنص.
- قاعدة معرفة JSON قابلة للتخصيص دون مفتاح API.
- تطبيع الحروف والتشكيل ومطابقة محافظة مع رد بديل عند غياب المعلومات أو التباس الإجابة.
- فصل محرك المطابقة عن الواجهة واختبارات للأسئلة والبيانات غير الصالحة.

هذا نموذج FAQ محلي؛ لا يتصل بـ Gemini أو أي نموذج لغوي، ولا ينفذ أدوات أو مهام وكيل مستقل. المطابقة النصية لا تفهم المعنى أو النفي كالنماذج اللغوية؛ اختبر صياغات العملاء قبل الاستخدام الفعلي. بيانات المتجر توضيحية. المحادثات تبقى في جلسة Streamlit الحالية ويتيح التطبيق تنزيلها اختيارياً.
